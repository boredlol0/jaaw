# jaaw

> **j**ust **a**nother **a**cademia **w**rapper

A wrapper for SMR Academia. Built mostly to mess around and learn.

## Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, GSAP
- **Backend:** Fastify + TypeScript

## Structure

```
src/          — Next.js app (pages, components, hooks, lib)
backend/      — Fastify API server with modular routes
  modules/    — auth, courses, attendance, marks, timetable, etc.
```

## Backend Modules

| Module      | Description |
|-------------|-------------|
| Auth        | Login/sessions |
| Courses     | Course listings |
| Attendance  | Attendance tracking |
| Marks       | Grade/marks view |
| Timetable   | Schedule display |
| Calendar    | Academic calendar |
| Health      | Health/wellness |
| Profile     | User profile |
